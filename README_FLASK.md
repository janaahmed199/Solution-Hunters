# NetWise — نسخة Flask (Python)

**Created by Jana & Sara**

تطبيق NetWise لإدارة استهلاك الإنترنت بذكاء — نسخة **Python + Flask** بنفس التصميم والمزايا.

## الملفات
- `app.py` — الباك إند بلغة Python باستخدام **Flask** (يربط الـ API ويستدعي Gemini).
- `index.html` — واجهة الموقع (HTML).
- `style.css` — التصميم (البينك الهادي + الأبيض).
- `script.js` — منطق الواجهة (JavaScript).
- `requirements.txt` — مكتبات Python المطلوبة.
- `.env` — مفتاح Gemini API (لا يظهر أبدًا في HTML أو JavaScript).

## طريقة التشغيل

1. أنشئ ملف `.env` وضع بداخله المفتاح:
   ```
   GEMINI_API_KEY=ضع_مفتاحك_هنا
   ```
   (يمكنك نسخ `.env.flask.example` إلى `.env`)

2. ثبّت المكتبات:
   ```bash
   pip install -r requirements.txt
   ```

3. شغّل التطبيق:
   ```bash
   python app.py
   ```

4. افتح المتصفح على:
   ```
   http://127.0.0.1:5000
   ```

## المزايا
- إدخال اسم العميل ورقم تليفونه + جيجا الباقة والمستهلك والأيام الباقية.
- حساب **الحد اليومي** تلقائيًا لتكفي الباقة لآخر الشهر.
- **تنبيهات ذكية**: تنبيهان عند تجاوز الحد ثم **حظر الإنترنت ساعة**.
- **إلغاء الحظر في الطوارئ** من الإعدادات.
- **تحليل استهلاك كل تطبيق عبر Gemini API** + بيانات افتراضية واقعية.
- الخطة **المجانية** + الخطة **المدفوعة** (أول شهرين مجانًا).
- قاعدة بيانات محلية بسيطة عبر SQLite (`netwise.db`) تُنشأ تلقائيًا.

> ملاحظة: إذا لم يُضبط `GEMINI_API_KEY`، يعمل التطبيق بتحليل تقديري ذكي بدل تعطّله (مناسب للـ Demo).
